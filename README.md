## Accuracy and safety

- Module status is taken from the committed module index when available; the journal does not infer completion from one function.
- Code snippets come from the committed source revision above. They are snapshots, not automatically executable instructions.
- Historical commits can span multiple modules and shared files. Use the commit links to verify attribution.
- Secrets and local configuration files are intentionally excluded. Please review generated notes before sharing a public branch.
- Tests are **not executed** by the journal generator. It only documents code and how to test.
- This does not reconstruct exact ChatGPT conversation turns or uncommitted edits.
